# Planto 🌱

Planto is an iOS plant care app that helps users manage their plants and watering reminders. It makes it easier to organize plant care details and track daily watering progress.

## Main Features

- Add, edit, and delete plant reminders.
- Set watering frequency and water amount.
- Organize plants by room and light requirements.
- Mark plants as watered.
- Track daily watering progress.
- View an All Done screen when today's reminders are completed.
- Schedule local watering notifications.
- Save plant information locally.

## Technologies Used

- **Swift** – Application programming language.
- **SwiftUI** – User interface development.
- **MVVM** – Organizing Models, Views, and ViewModel logic.
- **Data Modeling** – Struct, Class, Enum, and Optional.
- **Observation** – Updating the interface when data changes.
- **UserDefaults & Codable** – Saving and loading plant information.
- **UserNotifications** – Scheduling local watering reminders.
- **SF Symbols** – System icons.
- **Liquid Glass** – Button styling.
- **Icon Composer** – App icon configuration.
- **Xcode** – Development and testing.
